# Large Scale IT and Cloud Computing Project 
Bookstore as an IT-supported business proccess

## **Overview**
This repository contains the backend implementation for a scalable e-commerce bookstore platform. The system supports user authentication, book browsing, cart management, payment processing, and order delivery. Designed with modularity, scalability, and efficiency in mind, the project utilizes cloud technologies and containerization to ensure robust performance.
